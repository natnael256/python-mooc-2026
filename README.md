# Python Programming MOOC 2026 - University of Helsinki

This repository contains my personal solutions for the [Python Programming MOOC 2026](https://programming-26.mooc.fi/) offered by the University of Helsinki.

## About the Course

The course is divided into two modules totaling 10 ECTS credits:
*   **Introduction to Programming (Parts 1-7):** Covers the basics of algorithms, control structures, subprograms, and data structures.
*   **Advanced Course in Programming (Parts 8-14):** Dives deeper into object-oriented programming, class hierarchies, recursion, and game development.
